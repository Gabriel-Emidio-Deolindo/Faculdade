🏹 Funções Arrow em JavaScript
As funções arrow (ou funções flecha) foram introduzidas no ES6 (ECMAScript 2015) e oferecem uma sintaxe mais concisa para escrever funções em JavaScript.

Sintaxe básica:
javascript
// Função tradicional
function somar(a, b) {
    return a + b;
}

// Função arrow equivalente
const somar = (a, b) => {
    return a + b;
}

// Versão ainda mais concisa (quando tem apenas uma expressão)
const somar = (a, b) => a + b;
Características importantes:
Sintaxe reduzida: Remove a palavra-chave function e usa =>

Return implícito: Se o corpo da função tiver apenas uma expressão, o retorno é automático

Não tem seu próprio this: Herda o this do contexto onde foi definida

Não pode ser usada como construtora: Não funciona com new



Exemplo de Função Arrow com base no seu código
Código original (tradicional):
javascript
// Função tradicional
function calcularQuadrado(numero) {
    return numero * numero;
}
Mesma função com Arrow Function:
javascript
// Arrow function com sintaxe completa
const calcularQuadrado = (numero) => {
    return numero * numero;
};

// Arrow function com retorno implícito (mais concisa)
const calcularQuadrado = (numero) => numero * numero;

// Se tivesse apenas um parâmetro, poderia até remover os parênteses
const calcularQuadrado = numero => numero * numero;

📝 Atividade 1 - Nível Fácil
Enunciado:
Modifique a função que trata o evento submit do formulário para também ser uma arrow function, mantendo a mesma funcionalidade.

Solução:
javascript
// Arrow function para o cálculo
const calcularQuadrado = (numero) => numero * numero;

// Arrow function para o evento
document.getElementById('numeroForm').addEventListener('submit', (event) => {
    event.preventDefault();
    
    const numero = parseFloat(document.getElementById('numero').value);
    const resultado = calcularQuadrado(numero);
    
    document.getElementById('resultado').textContent = `O quadrado de ${numero} é ${resultado}`;
});

JavaScript (script1.js com arrow functions):
javascript
// Arrow functions para cada operação matemática
const quadrado = (num) => num * num;
const cubo = (num) => num * num * num;
const raizQuadrada = (num) => Math.sqrt(num);

// Função para formatar o resultado (também é arrow function)
const formatarResultado = (num, operacao, resultado) => {
    const operacoes = {
        quadrado: `O quadrado de ${num} é ${resultado}`,
        cubo: `O cubo de ${num} é ${resultado}`,
        raiz: `A raiz quadrada de ${num} é ${resultado.toFixed(2)}`
    };
    return operacoes[operacao] || 'Operação inválida';
};

// Event handler como arrow function
document.getElementById('numeroForm').addEventListener('submit', (event) => {
    event.preventDefault();
    
    // Obtendo valores do formulário
    const numero = parseFloat(document.getElementById('numero').value);
    const operacao = document.getElementById('operacao').value;
    
    // Validando entrada
    if (isNaN(numero)) {
        document.getElementById('resultado').textContent = 'Por favor, digite um número válido!';
        return;
    }
    
    // Executando a operação escolhida
    let resultado;
    switch(operacao) {
        case 'quadrado':
            resultado = quadrado(numero);
            break;
        case 'cubo':
            resultado = cubo(numero);
            break;
        case 'raiz':
            if (numero < 0) {
                document.getElementById('resultado').textContent = 'Não existe raiz quadrada de número negativo!';
                return;
            }
            resultado = raizQuadrada(numero);
            break;
    }
    
    // Exibindo resultado formatado
    document.getElementById('resultado').textContent = formatarResultado(numero, operacao, resultado);
});

// Exemplo de arrow function com array methods (demonstração adicional)
console.log('Exemplos de números:', [2, 3, 4].map(quadrado)); // [4, 9, 16]
🎯 Explicação do uso de Arrow Functions neste contexto:
quadrado, cubo, raizQuadrada: Arrow functions simples com retorno implícito

formatarResultado: Arrow function com múltiplas linhas (precisa das chaves e return)

Event listener: Arrow function como callback do evento submit

map(quadrado): Demonstra como arrow functions são ótimas para métodos de array

Vantagens observadas:
Código mais conciso e legível

Comportamento previsível do this (embora não usado aqui)

Perfeito para funções puras e operações matemáticas

Enunciado:
Amplie a calculadora para oferecer duas operações: quadrado e cubo do número. Utilize funções arrow para ambas as operações e adicione um seletor (radio button ou select) no HTML para o usuário escolher a operação desejada.

Modificações necessárias:

JavaScript (script1.js atualizado):
javascript
document.getElementById('numeroForm').addEventListener('submit', function(event) {
    event.preventDefault();
    
    const numero = parseFloat(document.getElementById('numero').value);
    const operacao = document.querySelector('input[name="operacao"]:checked').value;
    
    let resultado;
    
    // Utilizando arrow functions para as operações
    const quadrado = (n) => n * n;
    const cubo = (n) => n * n * n;
    
    if (operacao === 'quadrado') {
        resultado = quadrado(numero);
        document.getElementById('resultado').textContent = `O quadrado de ${numero} é ${resultado}`;
    } else {
        resultado = cubo(numero);
        document.getElementById('resultado').textContent = `O cubo de ${numero} é ${resultado}`;
    }
});
Explicação da solução:
Criamos duas funções arrow: quadrado e cubo

Ambas utilizam a sintaxe reduzida com retorno implícito

Adicionamos botões de rádio para o usuário escolher a operação

O resultado é exibido de forma mais descritiva

✅ Benefícios das funções arrow neste contexto:
Código mais limpo e fácil de ler

Menos propenso a erros com o escopo do this

Ideal para funções simples como operações matemáticas

Perfeito para callbacks (como em eventos e métodos de array)

As funções arrow são especialmente úteis em situações como esta, onde temos operações matemáticas simples e funções que serão usadas como callbacks.
